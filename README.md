# Rice Leaf Disease Detection Using CNN

## Project Overview
This project focuses on detecting and classifying rice leaf diseases using Convolutional Neural Networks (CNN). The main objective is to identify diseases in rice plants by analyzing images of rice leaves using Deep Learning techniques.

## Objectives
- Detect diseases in rice leaves using image processing.
- Classify healthy and diseased rice leaves.
- Support early identification of rice plant diseases.
- Help improve crop health and agricultural productivity.

## Technologies Used
- Python
- Deep Learning
- Convolutional Neural Network (CNN)
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Dataset Collection
2. Image Preprocessing
3. Data Augmentation
4. CNN Model Building
5. Model Training
6. Model Evaluation
7. Disease Prediction

## Project File
- Rice_Leaf_Disease_Detection.ipynb – Contains the implementation and model training process.

## Applications
- Early detection of rice leaf diseases.
- Smart agriculture.
- Crop health monitoring.

## Conclusion
This project demonstrates how Deep Learning and CNN can be used to identify rice leaf diseases from images and support better agricultural practices.
